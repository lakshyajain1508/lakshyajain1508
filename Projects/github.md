# What is GitHub ?

GitHub is a website where developers save, manage, and share their code projects.

Simple words:

* Your code = files
* GitHub = online storage + teamwork platform for code

It is mainly used by programmers, web developers, app developers, data scientists, etc.

You can think of it like:

* **Google Drive for code**
* * teamwork
* * project history
* * portfolio for jobs

Official website: [GitHub](https://github.com?utm_source=chatgpt.com)

---

# What is Git?

Before GitHub, understand **Git**.

## Git = Version Control System

It tracks changes in code.

Example:

You made a website.

* Day 1 → working fine
* Day 2 → you changed code and website broke

Git helps you:

* go back to old version
* track who changed what
* save project history

---

# Difference Between Git and GitHub

| Git              | GitHub                 |
| ---------------- | ---------------------- |
| Tool/software    | Website/platform       |
| Runs on computer | Runs online            |
| Tracks changes   | Stores projects online |

Simple:

* Git = engine
* GitHub = cloud platform using Git

# Important Words You Should Know

## Repository (Repo)

Project folder on GitHub.

Example:

* portfolio website repo
* pandas learning repo

---

## Commit

Saving changes with message.

Example:

```bash
Added login page
```

Think:
“Checkpoint save”

---

## Push

Upload code from computer to GitHub.

---

## Pull

Download latest code from GitHub.

---

## Clone

Copy project from GitHub to your computer.

---

## Branch

Separate version for testing new features.

Main project stays safe.

---

## Merge

Combine branch changes into main project.

---

## README.md

Project introduction file.

Contains:

* project name
* features
* installation
* screenshots

Almost every repo has it.

---

# Basic Workflow (Very Simple)

## Step 1

Create project on computer

↓

## Step 2

Initialize Git

```bash
git init
```

↓

## Step 3

Save changes

```bash
git add .
git commit -m "First commit"
```

↓

## Step 4

Upload to GitHub

```bash
git push
```
