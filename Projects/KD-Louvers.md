# KD-Louvers

A simple static website showcasing louvers and products for KD-Louvers.

## Overview
- Static HTML/CSS/JS site with a product catalog and contact page.

## Features
- Product catalog and product pages
- Contact form (client-side)
- Responsive layout using `css/style.css`

## Project structure
- [index.html](index.html) — Home page
- [catalog.html](catalog.html) — Product catalog
- [products.html](products.html) — Products listing
- [contact.html](contact.html) — Contact page
- [css/style.css](css/style.css) — Main stylesheet
- [js/main.js](js/main.js) — Main scripts
- [js/products.js](js/products.js) — Products scripts
- [js/contact.js](js/contact.js) — Contact form script
- `Products/` — Product images and assets
- `assests/` — Additional media (logo, video)

## Local preview
The site is static — open `index.html` in your browser, or serve it with a simple HTTP server for best results.

Using Python 3:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Development notes
- Edit styles in [css/style.css](css/style.css).
- Edit client logic in files under `js/`.
- Add product assets under `Products/` and `assests/`.
